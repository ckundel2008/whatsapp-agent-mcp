# Support

This is a community project. Report reproducible defects and documentation
issues at [GitHub Issues](https://github.com/ckundel2008/whatsapp-agent-mcp/issues).
Do not include phone numbers, message text, QR codes, session files, tokens,
cookies or screenshots containing private WhatsApp data.

Before reporting a UI problem, record the candidate version, macOS and Node
versions, the client surface (native UI or loopback browser panel), and the
non-sensitive error message. Confirm whether the local daemon status command
works. Native UI support and public directory publication are currently
unverified.

The project cannot provide WhatsApp/Meta support, guarantee account safety, or
promise message delivery. For an ambiguous send result, do not retry; check
the chat manually and report the evidence.
